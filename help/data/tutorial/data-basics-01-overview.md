## What is the Data context?

The **Data** context in Fusion Spectra is the home for data management
capabilities — browsing datasets, inspecting data lineage, and managing
data sources connected to the platform.

## Current status

The Data context is under active development. Features are being added
progressively. Check back in future releases for:

- Dataset browsing and search
- Data source connections
- Lineage and dependency tracking
- Data quality metrics

## In the meantime

While Data capabilities are being developed, you can:

- Use **Fusion Index** (`/fusion-index`) to store and version data files
  alongside other artifacts.
- Use **Weave** (`/pipelines`) to build and schedule data pipelines that
  process and transform your data.
- Use **Fusion Forge** (`/forge`) to build Python environments for
  data processing workloads.
